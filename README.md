## 🌟 Overview

**Classroom Frontend (Tablawy OS)** is the client application for the Classroom Platform ecosystem. Built on **React 19** and **Refine v5**, it provides role-based workspaces for administrators, instructors, and students—featuring real-time classroom collaboration, interactive whiteboards (`Excalidraw`), live video sessions (`Jitsi`), rich-text/LaTeX assessments (`TipTap` + `KaTeX`), QR attendance scanning, and offline-first resilience (`Dexie` IndexedDB + PWA service workers).

---

## 🧠 Agentic UI & Educational Features

* **🤖 System Self-Reflection Dashboard**: Real-time health, grading fairness, and telemetry reports generated by the **Janitor Agent**.
* **🧬 Student Learning DNA**: Contextual pedagogical insights and risk indicators integrated directly into class rosters and gradebooks.
* **👍 Continuous Feedback Loop**: Embedded sentiment and accuracy feedback controls across all AI-assisted grading and tutoring workflows.
* **📡 Offline-First & Resumable Uploads**: Built-in IndexedDB caching (`Dexie`), Workbox PWA precaching, and `tus-js-client` resumable media uploads for low-bandwidth environments.
* **🌍 Strict Multi-Namespace i18n**: Full localization and RTL/LTR support powered by `i18next` and `zod-i18n-map`.

## 🏗️ Enterprise Architecture & Patterns

We strictly adhere to industrial architectural standards to ensure security, maintainability, and responsiveness. See **[DEVELOPMENT_PATTERNS.md](./DEVELOPMENT_PATTERNS.md)** and **[API_REFERENCE.md](./API_REFERENCE.md)** for complete specifications:

1. **Component Deconstruction**: Large domain views are decomposed into atomic, testable widgets and feature modules.
2. **Zero-Direct-Call Policy**: The client never invokes external AI SDKs directly; all AI requests route through the authenticated backend proxy with quota and sanitizer guards.
3. **Role-Based Access Control (RBAC)**: Centralized Refine v5 `accessControlProvider` synchronized with backend permissions.
4. **Offline & Rural Hardening**: Local-first state persistence with `Dexie` and background sync queues.
5. **Containerized Production Delivery**: Hardened multi-stage `Dockerfile` with custom `nginx.conf.template` and strict CSP headers (`security-headers.conf`).

## 🚀 Setup & Installation

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/galilio2023/classroom-frontend.git
cd classroom-frontend
npm install
```

### 2. Configure Environment (`.env.development`)
Copy `.env.example` to `.env.development` and configure the backend endpoints:
```env
VITE_API_URL=http://localhost:8000/api
VITE_SOCKET_URL=http://localhost:8000
VITE_TUS_ENDPOINT=http://localhost:8000/api/upload/resumable
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Production Build
```bash
npm run build
npm start
```
